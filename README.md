# 🏪 小店大亨 · 商店 × 合成

一个单文件网页放置游戏（商店经营 + 合成升级 双循环）。无依赖、无构建，打开即玩。

## 在线玩

**https://xtuhjh.github.io/shop-tycoon/**

手机上建议用「添加到主屏幕」，可以全屏当 App 玩。

## 玩法

| 线路 | 做什么 | 花什么 |
|------|--------|--------|
| 🏪 **商店线** | 货架按时间自动生产商品 → 端给客人 → 客人付钱走人 | 💰 金币：升级店铺、开新店、解锁商品 |
| 🔮 **合成线** | 花能量生成产品 → 两个相同等级合并升级 → 首合出高等级自动上架货架 | ⚡ 能量：生成产品、升级合成台 |

### 核心循环

```
货架按时掉货 ──> 客人排队点单 ──> 你端菜上桌 ──> 客人付款走人
    ↑                                                    │
    └──── 首次合出的新商品自动上架 ←── 合成台合并升级 ←────┘
```

- **钱不会自己涨**：只有把商品端给客人、客人付钱那一刻才进账
- **每样商品最多囤 5 件**，满仓停产（所以要回来端菜）
- 🍽️ **当服务员**：点客人选中他 → 他要的菜在货架亮起绿色「端菜」→ 点它上菜（菜会飞向客人）→ 凑齐自动结账
- 📋 **客人会跟着你成长**：合成出新商品后，后续客人的订单里就会出现新菜
- 🐾 **宠物**：吧台边的小家伙，点它摸头、用货架上做好的菜投喂它长大（5 个成长阶段）
- 🥣 宠物长大有回报：Lv.2 帮你捡金币 · Lv.3 全场售价 +5% · Lv.4 客人赏金 +10% · Lv.5 稀有客人翻倍
- 🥚 **6 个隐藏彩蛋**：连点招牌、招财猫、神秘宝箱、隐藏套餐、深夜限定客（23:00~02:00）、每日开店礼，可在 ⚙️ 里看彩蛋图鉴
- 🛍️ **点击店铺条切换经营的店**：小摊⚡翻倍、食堂客人奖励×1.6、白金餐厅稀有钱×2……
- ✨ **隐藏稀有钱**：合并时小概率蹦出 🍀 🌈 👑，会有「稀有客人」出天价点名要它
- 📦 **出货模式**：合成台里的产品可点击换成能量
- 🏆 Lv.12 两个满级对撞有彩蛋

## 数值一览

- 商品 12 级：🍋柠檬水 → 🌟传世珍馐（售价 5 → 1,000,000）
- 店铺 6 档：🛖街边小摊 → 🏪便利店 → ☕文艺咖啡馆 → 🍽️深夜食堂 → 🏛️白金餐厅 → 💎米其林殿堂（售价倍率 ×1 → ×100）
- 开新店价格按你的收入自动缩放（永远约等于「攒一会儿」），不会出现要么秒买要么挂几小时
- 稀有物：🍀幸运三叶草 / 🌈彩虹圣代 / 👑黄金招牌

## 本地运行

```bash
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/index.html
```

存档存在浏览器 localStorage（`shopMergeGame_v1`），换设备不通用；⚙️ 菜单里可重置。

## 技术说明

- 单个 `index.html`，内联 CSS + 原生 JS，零依赖
- 渲染：DOM 重建 + CSS 动画（飞菜、金币爆散、卡片脉冲）
- 游戏循环：`setInterval(tick, 200)`，每 10 秒自动存档
- 交互元素均为真实 `<button>`（键盘/读屏器可访问）
