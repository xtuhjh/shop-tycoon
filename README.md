# 🏪 小店大亨 · 商店 × 合成

一个单文件网页放置游戏（商店经营 + 合成升级 双循环）。无依赖、无构建，打开即玩。

## 在线玩

**https://xtuhjh.github.io/shop-tycoon/**

手机上建议用「添加到主屏幕」，可以全屏当 App 玩。

## 玩法

| 线路 | 做什么 | 花什么 |
|------|--------|--------|
| 🏪 **商店线** | 点大图标开火→再点加速→做好再点端给客人（一颗图标走完全流程）| 💰 金币：升级店铺、开新店、解锁商品 |
| 🔮 **合成线** | 花能量生成产品 → **拖动/点击**合并升级 → 首合出高等级自动上架 | ⚡ 能量：生成产品、升级合成台 |

### 每家店有自己的菜单和客人

- 每家店只卖 **4 道自家招牌菜**（小摊卖柠檬水/糖葫芦/烤肠，咖啡馆卖美式/拿铁/冰滴…），**两道一行正好两行，不用上下拉**
- 每道菜绑定一个**等级**：等级决定售价与解锁条件（合成台合出该等级才上架）。合成台＝中央厨房按等级出产品，门店负责做成自家招牌——同一个 Lv.5，咖啡馆做成「手冲美式」、深夜食堂做成「炭烤串」
- 店的菜单等级区间逐级上移（小摊 Lv.1-4 → 便利店 Lv.3-6 → … → 白金/米其林 Lv.9-12），相邻两店有重叠，所以开新店时通常已有菜能卖
- **客人也不共享**：每家店有独立的客人队列和货架库存，切店＝换一批客人；客人只点你在这家店已经上架的菜（不会点到做不出来的东西）
- 客人就站在**顶部的吧台里**（页面最上方，手机上不怕被手挡住）：气泡里是一个**碟子**，要的菜摆在碟子上（一样居中、两样并排、三样三角，灰=没做/橙=一半/绿=齐了）+ 赏金 + 「送走」，**客人旁边有读秒牌** ⏳

### 合成台玩法

- **36 种口味**：每个等级有 3 种口味（外形不同、机制一致），生成时随机出，可在合成台看收集进度
- **拖动合并**：拖一道菜到同级菜上直接合并——拖起来时**所有能合的同级格子一起发光**、悬停直接显示**合出的等级**；拖到空格 = 移动整理；拖到「出货模式」按钮 = 直接换能量。格子上闪的 💰 角标 = 有客人正在等这个等级
- **自己找、自己合**：刻意不做"一键合并/自动整理"，找同级菜、决定先合哪个就是核心乐趣
- **合并暴击**：10% 概率直接多升一级（金色爆发特效）
- **🔥 连击**：6 秒内连续合并不停手，连击越猛——×2 起每合一手额外送能量，×3 暴击率 +15%，×5 必暴击，×8 稀有物出现率 ×3（借鉴 Travel Town / Merge Hotel 的连击手感）
- **🧺 同级加成**：同一等级在棋盘上攒够 3 个再合暴击率 +15%，攒够 5 个再合必暴击——"攒着合还是分批合"是个真取舍（借鉴 Merge Dragons 的 5 合 2）
- **🍽️ 客人等什么，合成台直接告诉你**：面板上列出当前客人订单对应的等级，合出来的菜正好能上架
- **隐藏稀有钱**：合并时小概率蹦出 🍀 🌈 👑

### 核心循环

```
点「制作 👨🍳」开火 ──> 等几秒出餐 ──> 吧台里的客人点单 ──> 你端菜上桌 ──> 客人付款走人
    ↑                                                                    │
    └──── 首次合出的等级自动上架（各店对应招牌菜） ←── 合成台合并升级 ←────┘
```

- **自己做菜**：出餐台上每道菜都要点「制作 👨🍳」开火，等几秒才出餐（升级店铺缩短时间），不再自动出餐；稀有菜例外，会自己慢速补货
- **钱不会自己涨**：只有把菜端给客人、客人付钱那一刻才进账
- **每样菜最多囤 5 件**，满仓时制作按钮变「已满」（所以要回来端菜）
- 🍽️ **当服务员**：客人要的菜会亮起绿色「上菜」→ 点它上菜（服务员端过去）→ 凑齐自动结账、客人走人下一位补位
- ⏳ **客人有耐心**：**客人旁的读称牌显示剩余秒数**（越少越红），剩四分之一变脸 😠；见底气走（赏金没了 + 冷场 12 秒无新客）。多点几下加速、及时上菜就是留客手段；「送走」换人不会气走人
- 客人点几样随菜单丰富度放开：菜越全，点满 3 样的大单越多（每种还可要 1~3 件）
- 📋 **客人的口味会跟着你成长**：合成出更高等级后，卖这个等级的店，客人订单里就会出现新菜
- 🐾 **宠物图鉴（8 个品种）**：🐶小奶狗 · 🐱巷口猫 · 🐰团子兔 · 🦊偷吃小狐 · 🐼熊猫团子 · 🐧围裙企鹅 · 🐲灶王小青龙 · 🦄星光独角兽。外观用同一套可爱底座参数化生成（耳型/尾型/嘴型/花纹/配色不同），一亮相就能分辨
- 🥣 **养成**：点它摸头涨心情与亲密度，用当前店做好的菜投喂涨成长；每只**独立成长**到 5 阶，长大同时解锁项圈 → 围巾 → 星环，形象肉眼可见地变化
- 🔧 **每只技能不同，只有出勤的那只生效**（换宠物＝换一套加成）：狗捡金币 · 猫上菜小费 · 兔制作提速 · 狐抬售价 · 熊猫抬赏金 · 企鹅离线收益 · 龙稀有菜补货＋稀有客人 · 独角兽全能
- 💗 **心情影响发挥**：心情 ≥70 多给 10%，低于 30 只发挥一半，所以"照顾它"是有收益的
- 🎁 **出门带特产**：它每隔几分钟自己出门溜达，回来叼一份特产（金币 / 能量 / 顺手带一道菜上架），离线期间也照常结算
- 🌙 **离线收益**：关掉页面店员会替你接待客人，回来一次结算（最多 8 小时）。算法是「按当前店菜单估一单赏金 ÷ 店员接待节奏 × 折扣」，所以挂机明显比手动玩慢——自己招呼客人永远更划算
- ✨ **怎么收集**：用某只"爱吃的等级"的菜投喂，有概率把新伙伴引来（图鉴里写了它爱吃什么）；也可以在图鉴里花金币直接招募
- 🥚 **6 个隐藏彩蛋**：连点招牌、招财猫、神秘宝箱、隐藏套餐、深夜限定客（23:00~02:00）、每日开店礼，可在 ⚙️ 里看彩蛋图鉴
- 🛍️ **点击店铺条切换经营的店**（换店＝换菜单、换客人、换货架库存）：小摊⚡翻倍、咖啡馆生产×1.5、食堂客人奖励×1.6、白金餐厅稀有钱×2……
- ✨ **隐藏稀有物（6 种）**：🍀幸运三叶草 · 🎐招财风铃 · 🌈彩虹圣代 · 🧧好运红包 · 👑黄金招牌 · 💎秘藏钻石。合并时约 **0.7%** 出货（第一次遇到之前有 3 倍保底），住在一个独立的「✨ 稀有」子标签页里，不占出餐台的位置
- 🏮 **稀有物不止能卖（镇店供奉）**：点稀有菜卡片上的「🏮 镇店」把它供奉给这家店当**镇店之宝**（消耗 1 件现货，之后它会自己慢慢补回来）→ 该店**永久加成**（🍀 售价+10% / 🎐 赏金+15% / 🌈 售价+20% 赏金+10% / 🧧 售价+15% 生产+20% / 👑 售价+35% 赏金+20% 生产+15% / 💎 售价+50% 赏金+25% 生产+30%）。**只对那一家店生效**，店铺条上会挂 🏮、吧台墙上会挂出镇店物
- ✨ **稀有物也能喂宠物**：成长远超菜品（220 / 420 / 700 / 1100 / 2400 / 5000）、心情直接拉满，还有 30% 概率把传说伙伴（🐲灶王小青龙 / 🦄星光独角兽）引来
- 📦 **出货模式**：合成台里的产品可点击换成能量
- 🏆 Lv.12 两个满级对撞有彩蛋

- 💌 **宠物会说情话**：摸头、心情好的时候偶尔蹦一句甜的，宠物面板里点「💌 听它说句话」随时听——每只品种都有自己的几句专属台词

## 账号与存档

- 进店时输入昵称就是账号，**进度按账号分别存在这台设备的浏览器里**；⚙️ →「账号」里可以切换 / 新建 / 删除账号
- 换设备或换浏览器：用账号面板里的 **📤 存档码**（整份存档压成一段文本，复制发给对方或存备忘录）→ 在另一台设备 **📥 导入**即可
- 说明：这是**纯前端**方案（GitHub Pages 上没有服务器），所以它不是账号密码级别的安全，也不做自动云同步；老玩家第一次输入昵称进店会自动继承本机已有进度

- 商品 12 级：🍋柠檬水 → 🌟传世珍馐（售价 5 → 1,000,000）
- 每家店 4 道招牌菜，按等级取价：小摊 Lv.1-4 / 便利店 Lv.3-6 / 咖啡馆 Lv.5-8 / 深夜食堂 Lv.7-10 / 白金餐厅与米其林 Lv.9-12
- 店铺 6 档：🛖街边小摊 → 🏪便利店 → ☕文艺咖啡馆 → 🍽️深夜食堂 → 🏛️白金餐厅 → 💎米其林殿堂（售价倍率 ×1 → ×100）
- 开新店是**固定价格**（¥8,000 → ¥120 亿），不随你的收入/余额浮动，可以安心盯着一个数攒钱；店铺条上每家未解锁的店都标着价格，点开还能看它卖什么、加成是什么
- 稀有物：🍀幸运三叶草 / 🌈彩虹圣代 / 👑黄金招牌

## 本地运行

```bash
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/index.html
```

存档存在浏览器 localStorage（`shopMergeGame_v1`），换设备不通用；⚙️ 菜单里可重置。
老存档会自动迁移：原来按等级的一整套货架，折算进各家店自己的菜单（进度不丢）。

## 技术说明

- 单个 `index.html`，内联 CSS + 原生 JS，零依赖
- 渲染：DOM 重建 + CSS 动画（飞菜、金币爆散、卡片脉冲）
- 游戏循环：`setInterval(tick, 200)`，每 10 秒自动存档
- 商店页是一个一体化店面：店铺条 → 吧台（客人 + 碟子摆盘订单 + 读秒，在最上面，手机上不被手挡）→ 服务员动线 → 出餐台（本店 4 道菜 = 4 颗大图标，点图标就做/加速/上菜）→ 后厨（机器做菜，宠物守在灶台旁）；主界面底部常驻「升级 / 开新店」，统计与玩法说明收在「⋯ 统计与说明」折叠条里
- 页面高度自适应：各带高度用 `clamp(...,…dvh,…)` 随屏幕伸缩，并向矮屏叠加三档媒体查询，320×568 ~ 414×896 均一屏放下、无需拖动
- 合成台的「生成 / 出货」按钮是固定操作坞，钉在屏幕底部不随页面滚动；客人订单气泡里的菜名、数量、进度都放大到不用眯眼的尺寸
- 客人数据：`state.shopQueue[i]`，货架：`state.shopStock[i]`，制作进度：`state.shopCook[i]`——按店索引，互不影响
- 交互元素均为真实 `<button>`（键盘/读屏器可访问）
